# v2 results

The v2 edition (`--v2`): shared-vocabulary subjects, a fourth crossed
phrasing, natural-null controls beside the phantoms, three contradiction
shapes aimed at token differencing, answer-readable credit, capability
flags, the additive score, and — since 2026-09-16 — the **path-shaped
read**: every file the world's code refs name is asked once, by path,
through `recall_path`, the way an edit hook asks (`docs/families.md`,
`docs/protocol.md`). Worlds under `worlds/v2/` (the same five specs as v1's
100/500/1500 and 500 seeds 2–3, regenerated byte for byte by a golden test).
The seven in-process arms and the four external adapters have run the
official ladder (500 and 1500, seed 1); the in-process arms also the three
seeds at 500.

## The path read

Every note in a world carries zero to three code refs of the shape
`src/<component>/<file>.rs`; 63–64 distinct files exist at every size, and
a file binds 2–15 live notes at 500 and 8–53 at 1500. Each file is asked
once, as a path, with no question around it: *pass* is a bound note
readable in the top five, `path_cover` the share of the bound notes the
top-k delivered. Three kinds of system show up:

- **A file channel.** engram's code-ref match (the file-read hook's own
  lookup), grep's substring match over the note files, and MemContinuum's
  `for-path` answer every file and cover 0.87–1.00 of what is bound.
- **A vector store handed a path.** `rag`, LangMem, Mem0 and cognee embed
  the path string and find the *component's* notes — enough for 0.56–0.68
  of files to show one bound note in the top five, never enough to cover
  the file (0.18–0.36).
- **Titles only.** tfidf tokenises the path and matches the component
  words; its short snippets never carry the refs (0.08–0.44).

The read is 63 of 3,042 tasks at 500 and 64 of 9,008 at 1500, so it moves
no headline by more than a point; it is a column, and it is the column
MemContinuum's author asked for (below).

## The TF-IDF arm, v1 against v2

`results/v1/reference-arms/500-seed1-tfidf.json` is the same arm on the v1
500 world: **564 at 61% success**, signal share 0.82, 99 tokens per answer
— above the reference system's v1 511 at 85%, which is the crack the field
submission reported (823 at 76% on the 1500 world). On v2 the same arm
scores **574 at 43%**, 167 under the reference system's 741, and the
mechanisms it rode are each visible in a column:

- the idf oracle is dead — `phantom_fp` 1.00 (it was 0.00 on v1: every
  word of a v2 phantom subject was written somewhere) and `natural_fp`
  1.00;
- the crossed phrasing is unreachable — `crossed_r@5` 0.00, and the four
  phrasings weigh equally, so retrieval falls from 61% to 45%;
- `stale_above` 0.70: the stale sibling's shorter title wins cosine;
- the path read is out of reach for a title index — `path_r@5` 0.21;
- the contradiction column keeps what token differencing can do (`value`
  and `unit`, tier-1 recall 0.38) and shows what it cannot: `reworded`
  and `clause` positives are missed and the `synonym` negative is not
  flagged, which is the trap working both ways.

What it still earns is honest: 100 token points (140 tokens per answer)
and 41 signal points, plus the families it attempts — temporal, deletion,
a fair share of drift. That is where the additive score puts a lexical
system: above the flat stores that show ten whole notes, well under a
memory that knows what it knows.

## Two versions of the reference system

The reference row is Engram Alpha **0.9.6**; 0.9.5 was measured first, on
the same worlds and the same day, and its receipts stay under
`reference-arms/0.9.5/`. Its v2 number was not a v1 number regraded: three
columns had moved against v1, and each was a finding about the product,
not the bench —

1. **`crossed_r@5` 0.02** (rag 0.17): a question sharing no content word
   with its note is where a hybrid ranker lands under pure cosine.
2. **`hedge` 0.40**: the calibrated "not in memory" line declined 40% of
   answerable v2 questions. On v2 a decline on an answerable question is
   zero signal, so the signal score is 36 where the retrieval focus alone
   would give about 60.
3. **Contradiction 46% (t1 0.04) and drift 47%** against 75% and 91% on
   v1: the title-nomination gate barely raised the v2 `value` flips on
   three-word lowercase subjects.

Between 0.9.5 and 0.9.6 the third moved and the first two did not:
contradiction 46% → **70% (68–72)** (tier-1 recall 0.04 → 0.79, tier-2
0.08 → 0.56, tier-3 false alarm 0.00 → 0.05 on the `historical` trap),
drift 44% → **91%** on every seed, deletion 93% → **100%**
(`resurrection_warned` 0.81 → 1.00); `crossed_r@5` stays 0.02, `hedge`
0.39, abstention 100% → 99% (`natural_fp` 0.00 → 0.02 on two seeds).
Everything else — retrieval, currency, rationale, temporal, the path read,
the tokens — is the same to the digit. The score moves 739 → 816 at 500
and 718 → 801 at 1500.

The path read adds nothing new about it: the code-ref match is the
mechanism the file-read hook already runs, and it answers every file
(1.00 / 0.99).

v1 numbers made two claims: that the 2% rationale measured the wrong
channel (the agent reads `for-path`/`chain`, which deliver the whole

for the agent to judge. Both are now measured. Rationale went from 4% to
**100%** — every one of it is `structure_only` (0.95): the reason arrives

exactly the chain doing the work the author described. The path read is

moved from 295 to **392** at 500 and 287 to **380** at 1500 — one family,
